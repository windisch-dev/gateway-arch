# Gateway Arch Raising Gang

Run the Gateway Arch erection sequence in 3D. Stand on the iron at the working joint, ride the hook, and watch topping day (October 28, 1965).

It's one HTML file. No build step, nothing to install. Open `index.html` in a browser.

Built with Claude by Andrew Windisch, a former union ironworker. Sources are listed on the page, and anything that isn't from a drawing or a source is called out there too.

This is a learning study. It is not engineering, and it is not a rigging or erection plan.

More at [Steel Erection Field Notes](https://fieldnotes.andrewwindisch.com/).
